# torch.initial_seed

torch.initial_seed()[[source]](https://github.com/pytorch/pytorch/blob/e1994aea9ce307fb82feeb7524ab2c5d36771e4f/torch/random.py#L144)

Returns the initial seed for generating random numbers as a
Python long.

Note

The returned seed is for the default generator on CPU only.

Return type:

[int](https://docs.python.org/3/builtins/functions.html#int)
