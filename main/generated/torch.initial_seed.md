# torch.initial_seed

torch.initial_seed()[[source]](https://github.com/pytorch/pytorch/blob/fe3f518c806b6f1fb8acc283135e5414b8606887/torch/random.py#L144)

Returns the initial seed for generating random numbers as a
Python long.

Note

The returned seed is for the default generator on CPU only.

Return type:

[int](https://docs.python.org/3/library/functions.html#int)
